# API Minimalista da Fórmula 1

Este é um projeto de API minimalista desenvolvido com Fastify para fornecer informações sobre equipes e pilotos da Fórmula 1.

## Funcionalidades

- Listar todas as equipes da F1
- Listar todos os pilotos da F1
- Buscar um piloto por ID
- Obter equipes com seus respectivos pilotos


## Tecnologias Utilizadas

- Node.js
- Fastify
- TypeScript
