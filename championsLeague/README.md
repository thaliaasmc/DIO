# API Champions League


A API Champions League é uma API que permite gerenciar informações sobre pilotos (players) e clubes (clubs).


## Funcionalidades

### Pilotos
- **Listar pilotos**: Retorna uma lista de todos os pilotos registrados.
- **Filtrar piloto**: Retorna os dados do piloto encontrado.
- **Criar piloto**: Adiciona um novo piloto ao sistema.
- **Atualizar piloto**: Atualiza as informações de um piloto existente.
- **Deletar piloto**: Remove um piloto do sistema.


### Clubs
- **Listar clubes**: Retorna uma lista de todos os clubes registrados.
- **Filtras clube**: Retorna os dados do clube encontrado.
- **Criar clube**: Adiciona um novo clube ao sistema.
- **Deletar clube**: Remove um clube do sistema.

## Tecnologias Utilizadas
- Node.js
- Express
- TypeScript
