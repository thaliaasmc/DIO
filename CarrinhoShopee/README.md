# Carrinho de Compras Shopee

Este projeto simula um carrinho de compras inspirado na plataforma **Shopee**. Através desse sistema, você pode adicionar itens ao carrinho, ajustar quantidades e calcular o total da compra de maneira simples e eficiente.

## Funcionalidades

- **Adicionar Itens**: Permite adicionar produtos ao carrinho, incluindo nome, preço e quantidade.
- **Atualizar Quantidade**: Você pode aumentar ou diminuir a quantidade de cada item no carrinho.
- **Calcular Subtotal**: O sistema calcula o subtotal de cada item, multiplicando o preço pela quantidade.
- **Total do Carrinho**: O total final da compra é calculado somando os subtotais de todos os itens.

## Tecnologias Utilizadas

- **Node.js**: Para a implementação do sistema e processamento das operações.
- **JavaScript Assíncrono (Async/Await)**: Utilizado para simular operações assíncronas no processo de manipulação de itens no carrinho.
